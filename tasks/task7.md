# 完成秒杀功能

根据 `swagger-flash-sale.json`中接口信息，完成所有功能。

## 1. 商品详情的“立即抢购”功能

若某个sku处于秒杀活动中，则会显示一个“立即抢购”按钮，点击该按钮后，跳转到秒杀订单确认页面，该页面与普通订单确认页面类似。
若秒杀活动未开始，则disable该按钮，并显示倒计时。
若秒杀活动已结束，则显示活动已结束，具体形式由你决定。

## 2. 秒杀订单确认页面

在秒杀订单确认页面，点击提交订单后，会调用秒杀订单提交接口，该接口只会返回请求的状态，如果R.code==0则视为成功，自动将用户重定向到订单确认页面。若R.code!=0则视为失败，提示用户错误信息，错误信息在R.msg中。

## 3. 完善订单列表页面与订单详情页面

对于这两个页面，若订单处于代付款状态，则会显示一个“立即支付”按钮，点击该按钮后，跳转到订单支付页面。支付订单的接口在`swagger-order.json` 中。

订单状态：【0->待付款；1->待发货；2->已发货；3->已完成；4->已关闭；5->无效订单】

## 4. 随机码的获取

在秒杀活动未开始之前，后端接口返回的随机码字段将会被置空。因此在倒计时结束后，需要重新调用接口获取随机码，以便执行秒杀请求。
